What’s New:

**Critical Resource Management**
- **Enhanced Safeguards for Critical Resources**: Protect sensitive infrastructure components like production databases and Kubernetes node pools from accidental changes with new restrictions on deletion, disabling, and editing of sensitive fields.
- **Role-Based Access Control (RBAC)**: Ensure that only users with specific permissions (*write_critical_resources*) can modify or delete critical resources.
- **Audit Logs for Compliance**: All actions on critical resources are tracked for traceability, enhancing security and compliance.
