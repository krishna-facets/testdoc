# Release Notes – v1.0.0

*Release Date: October 25, 2023*

We are thrilled to announce the release of version 1.0.0, featuring the introduction of the Observability Dashboard and Workflows module. This release focuses on enhancing operational efficiency and resource management within the DevOps platform, providing users with streamlined monitoring and automation capabilities.

## ✨ New Features

- Introduced the **Observability Dashboard**, offering a unified view for real-time monitoring of application and infrastructure health. [Read more](https://github.com/Facets-cloud/Readme-Documentation)
- Launched **Workflows** feature, enabling Terraform module developers to define and execute operational workflows directly within their modules. [Read more](https://github.com/Facets-cloud/Readme-Documentation)

## 🔧 Improvements

- Enhanced the user interface for monitoring and managing workflows, providing detailed logs and statuses for each execution.
- Improved integration with existing monitoring tools to ensure seamless data aggregation within the Observability Dashboard.

## 🐞 Bug Fixes

- Fixed an issue where certain alert conditions were not being correctly displayed in the Observability Dashboard.
- Resolved a bug that caused inaccurate status updates in the Workflows execution logs.

## 📘 Documentation

- Updated the [Readme Documentation](https://github.com/Facets-cloud/Readme-Documentation) to include comprehensive guides on using the new Observability Dashboard and Workflows features.

## Optional Notes

- This release is backward compatible with previous versions. However, users are encouraged to review the updated documentation for optimal usage of the new features.
- Known Issues: We are aware of occasional performance lags when loading extensive historical data in the Observability Dashboard and are actively working on improvements.

### Observability Dashboard

#### Description

The Observability Dashboard is a powerful new feature designed to provide real-time, centralized visibility into application and infrastructure health. By consolidating metrics, logs, and traces into a single view, it enables efficient detection, investigation, and resolution of issues.

#### Use Cases

- **Unified Monitoring:** Access all service metrics, logs, and traces in one place.
- **Root Cause Analysis:** Quickly identify the root cause of issues by drilling down into logs and traces.
- **Request Tracing:** Follow distributed traces to optimize performance.
- **Custom Dashboards:** Tailor dashboard layouts to prioritize critical services.

#### Usage Instructions

1. **Accessing the Dashboard:** Navigate from the main menu with appropriate RBAC permissions.
2. **Customizing Your Dashboard:** Arrange widgets using a drag-and-drop interface.
3. **Monitoring Metrics:** Analyze time-series graphs and create custom queries.
4. **Log Integration:** Search and filter logs for comprehensive insights.
5. **Tracing Requests:** Visualize and analyze distributed traces.
6. **Managing Alerts:** Monitor, suppress, or acknowledge alerts effectively.

For further details, refer to our [Readme Documentation](https://github.com/Facets-cloud/Readme-Documentation).

### Workflows

#### Description

The Workflows feature introduces utility modules that allow Terraform module developers to define and execute operational workflows. These workflows extend Terraform modules beyond infrastructure provisioning, enabling tasks like pod restarts and database migrations.

#### Use Cases

1. **Operational Task Automation:** Automate tasks like database migrations.
2. **Enhanced Resource Management:** Execute workflows from the Facets UI, improving efficiency.
3. **Monitoring and Logging:** Gain insights and review historical executions.

#### Usage Instructions

- **Defining Utility Modules:** Create YAML definitions within Terraform modules.
- **Publishing Module:** Register utility modules as Tekton Tasks during preview or publish.
- **Discovering and Executing Workflows:** Use the Facets UI to trigger and monitor workflows.
- **Monitoring and Logging:** Access logs and execution statuses in real-time.

For further details, refer to the [Facets Readme Documentation](https://github.com/Facets-cloud/Readme-Documentation).
