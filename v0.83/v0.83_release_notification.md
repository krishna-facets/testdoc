# Upcoming Release – v2.0

This release is scheduled for deployment on November 15, 2023.

We are thrilled to introduce v2.0, a significant update focused on enhancing operational efficiency and monitoring capabilities for DevOps professionals. This release features two major additions: the Observability Dashboard and the Workflows feature, both designed to streamline processes and improve overall productivity.

## What’s Coming

- 📊 **Observability Dashboard**: A unified platform for real-time monitoring of application and infrastructure health.
- 🔄 **Workflows**: Empowering Terraform module developers with reusable, on-demand workflows for operational task automation.

## Why It Matters

These features are designed to simplify complex DevOps tasks. The Observability Dashboard consolidates metrics, logs, and traces from disparate tools, offering a central hub for system health insights. Meanwhile, Workflows enhance Terraform modules by integrating operational task automation, reducing manual overhead and enabling seamless module lifecycle management.

## Observability Dashboard

### Description
The Observability Dashboard provides a comprehensive, real-time view of application and infrastructure health, integrating metrics, logs, and traces into a single platform. This feature addresses inefficiencies caused by the reliance on multiple, disjointed tools.

### Use Cases
- **Centralized Monitoring**: Monitor system metrics, logs, and traces in one location.
- **Root Cause Analysis**: Quickly identify and resolve issues by correlating alerts with logs and traces.
- **Customizable Dashboards**: Tailor dashboards to prioritize critical metrics and services.
- **Tracing Requests**: Follow requests through distributed services for performance insights.

For detailed usage instructions, please refer to the documentation at [Facets-cloud Readme Documentation](https://github.com/Facets-cloud/Readme-Documentation).

## Workflows

### Description
Workflows in Facets allow Terraform module developers to define reusable, on-demand workflows, transforming utility modules into executable tasks within the Facets control-plane Kubernetes cluster.

### Use Cases
- **Operational Task Automation**: Automate tasks like database migrations as part of a module’s lifecycle.
- **Enhanced Module Functionality**: Extend Terraform modules to handle post-provisioning operations directly.
- **Seamless Integration**: Manage workflows via the Facets UI for enhanced visibility and control.

For configuration details and examples, visit [Facets Readme Documentation](https://github.com/Facets-cloud/Readme-Documentation).
