Heads up: Release v1.5 is coming soon!  
🚀 Scheduled for: October 25th

This release introduces the brand-new Observability Dashboard and enhances the Workflows feature, providing greater visibility and automation capabilities for your DevOps operations.

🔗 See what’s planned and what’s new: [Upcoming Release Changelog](https://readme.facets.cloud/changelog/upcoming-release-v1.5)

Below are the feature summaries for this release:

### Observability Dashboard

The new Observability Dashboard offers centralized visibility into your application and infrastructure health, consolidating metrics, logs, and traces into a single, customizable view. This feature aims to streamline operations and enhance incident response times by providing unified monitoring, root cause analysis, request tracing, and custom dashboards.

### Workflows

With the improved Workflows feature, Terraform module developers can now define operational workflows, such as pod restarts and database migrations, using utility modules. These workflows can be triggered and monitored directly through the Facets UI or API, allowing for enhanced operational management and automation of infrastructure resources.

For further details on these features and advanced configuration, please refer to our [Readme Documentation](https://github.com/Facets-cloud/Readme-Documentation).
