Heads up: Release v1.5 is coming soon!  
🚀 Scheduled for: November 20th

This release focuses on enhancing observability and automating workflows to streamline DevOps operations.

🔗 See what’s planned and what’s new: https://github.com/Facets-cloud/Readme-Documentation/upcoming-release-v1.5

Below are the feature summaries for this release.

### Observability Dashboard

#### Description
The new Observability Dashboard offers a consolidated, real-time view of application and infrastructure health, enabling faster issue detection and resolution. This integrated platform merges metrics, logs, and traces, reducing reliance on multiple tools such as Prometheus and Grafana.

#### Key Features
- **Centralized Monitoring**: View system metrics, logs, and traces in one place.
- **Root Cause Analysis**: Quickly correlate alerts with logs and traces.
- **Customizable Dashboards**: Personalize dashboards to prioritize critical metrics.
- **Tracing Requests**: Follow requests through distributed services for performance insights.

For detailed usage instructions and technical requirements, please refer to the full documentation on our [GitHub page](https://github.com/Facets-cloud/Readme-Documentation).

### Workflows

#### Description
The Workflows feature empowers Terraform module developers to define reusable, on-demand workflows or utility modules. These modules facilitate operational tasks like pod restarts and database migrations, which are transformed into executable Tekton Tasks.

#### Key Features
- **Operational Task Automation**: Execute tasks like database migrations as part of module lifecycle.
- **Enhanced Functionality**: Extend Terraform modules to handle post-provisioning operations.
- **Seamless Integration**: Manage workflows through the Facets UI for increased control.

Explore comprehensive guidelines and examples in our [Facets Readme Documentation](https://github.com/Facets-cloud/Readme-Documentation).
