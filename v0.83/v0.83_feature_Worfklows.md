# Release Notes: Workflows Feature

## Introduction

We are excited to introduce the new **Workflows** feature in Facets, designed to empower Terraform module developers by allowing them to define and embed reusable, on-demand workflows, known as utility modules, within their modules. This functionality extends the use of Terraform modules beyond infrastructure provisioning to encompass a broader range of operational tasks, such as pod restarts, database migrations, and cluster scaling.

## Use Cases

The Workflows feature is ideal for:

- **Operational Automation**: Automate operational tasks like restarting application pods or scaling clusters.
- **Database Management**: Execute database migrations as part of infrastructure updates.
- **Custom Processes**: Embed any custom operational logic that can be encapsulated within a container and executed in sequence.

## Key Features

- **Utility Module Definition**: Define workflows within Terraform modules using a standard YAML format.
- **Tekton Integration**: Automatically convert utility modules into executable Tekton Tasks.
- **UI and API Interaction**: Discover, trigger, and monitor workflows via the Facets UI and API.
- **Execution History**: View execution history and logs for each workflow run.

## Usage Instructions

### Defining a Utility Module

1. Create a YAML file within your Terraform module to define the workflow. Include the following sections:
   - `name`: Unique identifier for the workflow.
   - `acc_type`: Target cloud or system type (e.g., `aws`, `k8s`, `gcp`, `azure`).
   - `params`: List input parameters required by the workflow.
   - `steps`: Define ordered steps with the container image and command to execute.

   **Example:**
   ```yaml
   name: migrate_database
   acc_type: aws
   params:
     - name: target_db_url
       type: string
     - name: dry_run
       type: bool
   steps:
     - image: myorg/db-migrator:latest
       command: ["./migrate"]
       args: ["--url", "$(params.target_db_url)", "--dry-run=$(params.dry_run)"]
   ```

### Publishing a Module

- When you preview or publish a Terraform module, the Facets backend parses the defined utility modules and registers them as Tekton Tasks in the control-plane Kubernetes cluster. These tasks are then available in the Facets Resource Center for execution.

### Discovering and Executing Workflows

- Navigate to the **Workflows** section within the Facets Resource Center UI.
- Explore available workflows listed for each resource.
- Use the **Trigger** button to execute a workflow, providing necessary parameter values as prompted.
- Monitor execution status and view detailed logs and historical runs directly within the UI.

### Monitoring and Logging

- Facets monitors the execution of workflows and updates their status in real-time. Users can access detailed logs for each step of the workflow, which are preserved for future reference.
